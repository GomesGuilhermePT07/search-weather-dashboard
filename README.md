## 🌤️ Weather Dashboard Tool!

<div align="center">
  <p>A funny way to search and see how's the weather outside your house!</p>
</div>

  ### ❓ How does it work
   - The user adds a location
   - App will return the following results:
       - Real-time temperature
       - Conditions (e.g. "cloudy", "rain", etc.)
       - Correspondent icon
    
  ### ⚙️ Working tools
   - HTML, CSS, JS
   - API: OpenWeatherMap (free endpoint)

  No installing required, no frameworks, no Node.
  
  ### 📈 Possible improvements:
   - Add favorite locations
   - Add automatic location recognition
   - Add search history
   - Add aditional languages (e.g.: English, French, Italian, etc.)
